# 简历编辑器 · 个人作品

> 一个零依赖、开箱即用的浏览器端 A4 简历编辑器——把"排版焦虑"变成所见即所得。

## ✨ 核心亮点
- 🎯 **真实 A4 版式**：打印 / 导出零错位，不靠截图拼凑
- 🎨 **设计系统驱动**：南大紫 `#823A8F` 主色 + 5 级文本层级（name / subtitle / title / body / meta），保证整份简历视觉一致、层级清晰
- 💾 **自动保存**：localStorage 持久化（STORAGE_KEY: `resume_data_v4`），关掉浏览器不丢
- 📤 **一键导出**：html2canvas 截图，直接生成可发招聘方的图片
- 🧩 **纯前端零构建**：双击 HTML 即跑，无框架、无打包

## 🛠 技术实现
| 模块 | 方案 |
|---|---|
| 状态持久化 | localStorage 键控存储 |
| 内容导出 | html2canvas 截图 |
| 架构 | 单文件 HTML + 内联 CSS/JS，仅 html2canvas 一个外部依赖 |

## 📐 设计细节
- 主色南京大学紫 `#823A8F`，统一视觉识别
- 5 级文本样式体系，规范化简历信息层级
- 每 5 分钟自动保存机制，稳定性优先

## 🚀 使用
直接用浏览器打开 `简历编辑器.html` 即可编辑、预览、导出。
